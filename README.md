# Campaign-Template
Template for Organizing D&D 5e Campaigns with Markdown Files.

# Directory
- ***[Adventure Template](/Adventure%20Template/README.md).*** Template files for creating a SWAD (Settlement, Wilds, and Dungeon) adventure.
- ***[Bastions](/Bastions/README.md)***. Folder for your own copies of characters' bastion sheets.
- ***[Character Sheets](/Character%20Sheets/README.md)***. Folder for your own copies of players' character sheets.
- ***[Homebrew](/Homebrew/README.md)***. Folder for homebrew creations you made or plan on using.
- ***[Ideas](/Ideas/README.md)***. Folder for random ideas that you might use.
- ***[Journal](/Journal/README.md)***. Folder for your journal entries of each session.
- ***[Locations](/Locations/README.md)***. Folder for keeping locations that your characters are likely to return to.
- ***[Lore](/Lore/README.md)***. Folder for keeping lore about your setting so you can reference it.
- ***[Media](/Media/README.md)***. Folder for maps, handouts, tokens, and other media you use.
- ***[NPCs](/NPCs/README.md)***. Folder for keeping NPC sheets that your characters are likely to encounter again.
- ***[Past Adventures](/Past%20Adventures/README.md)***. Folder for storing your past adventures so you can refer back to them.
